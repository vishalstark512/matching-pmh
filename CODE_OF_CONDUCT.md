# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

**Positive:** empathetic language, constructive feedback, respect for differing viewpoints, graceful acceptance of criticism.

**Unacceptable:** sexualized language, trolling, insults, public or private harassment, publishing others’ private information without permission, other conduct inappropriate in a professional setting.

## Enforcement

Report issues to the repository maintainers via GitHub Issues or private contact listed on the project homepage. Maintainers may remove, edit, or reject contributions that violate this code.
