# D1 — Subspace nuisance (Lemma D1)

**When:** low-rank subspace \(W\) explains **class-aligned** cross-domain variation (T1, Office-31 with labels on both domains).

**Config:** `SigmaTaskConfig.for_subspace(rank=r)`

## Labeled estimation (paper / T1)

**PyTorch** — four tensors required:

```python
from pmh import SigmaTaskConfig, estimate_from_config

artifact = estimate_from_config(
    SigmaTaskConfig.for_subspace(rank=32),
    h_src,
    y_src,
    h_tgt,
    y_tgt,
    seed=0,
    n_pairs_per_class=40,
)
# artifact.metadata["w"]  # [d, r] basis
```

Or: `estimate_sigma_task(x_src, y_src, x_tgt, y_tgt, method="D1", rank=32)`.

**Unlabeled** domain Gram only → use **`method="D4"`**, not D1.

Legacy unlabeled helper: `pmh.estimators.estimate_d1_gram_unlabeled` (not paper D1).
